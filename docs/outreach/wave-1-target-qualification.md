# Wave 1 Target Qualification

Updated: 2026-07-07

## Must pass (all)

- [ ] Site is **indexed** and reachable (not parked/expired)
- [ ] Topical relevance: casino editorial, crypto, payments, RG, or South Asia finance
- [ ] No obvious **PBN/spam** footprint (thin pages, unrelated outbound links)
- [ ] Contact path exists (email, form, or editorial guidelines page)
- [ ] Link placement would be **editorial** (article, resource list, directory profile)

## Must fail (reject)

- Link farms, Fiverr SEO gigs, automated comment sections
- Hacked pages, malware warnings, adult/pharma neighborhoods
- Sites demanding paid exact-match anchors
- Operator sites asking for reciprocal gambling promotion
- Pages with no plausible editorial context for CasinoPulse assets

## Scoring (manual)

| Factor | Weight | Notes |
|--------|--------|-------|
| Topical relevance | High | Payment/crypto/RG fit |
| Authority estimate | Medium | DR/Ahrefs if available; estimate OK |
| Linkability | High | Resource pages, directories, guides |
| Response likelihood | Medium | Active blog vs static directory |
| Policy risk | High | Reject if violates prohibited tactics |
