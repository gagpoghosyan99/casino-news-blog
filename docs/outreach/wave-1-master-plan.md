# Wave 1 Outreach Master Plan

Updated: 2026-07-07  
Sprint: **CASINOPULSE_P7**

## Objective

Move from technical SEO readiness to **manual authority execution** — editorial backlinks, resource citations, and directory profiles — without violating CasinoPulse link policies.

## Scope (Wave 1)

- **18 qualified targets** in [outreach-tracker.csv](../authority/outreach-tracker.csv)
- **6 email sequence types** (see [wave-1-email-sequences.md](./wave-1-email-sequences.md))
- **Anchor mix:** 70% branded, 20% naked URL, 10% partial-match, 0% spam exact-match
- **Timeline:** 6 weeks active outreach + 2 weeks monitoring

## Weekly cadence

| Week | Activity |
|------|----------|
| 1 | Finalize target list; send 5 initial emails (RG + crypto citations) |
| 2 | Send 5 directory/comparison pitches; log responses |
| 3 | Follow-up 1 for week-1 batch; send 4 payment-blog pitches |
| 4 | Follow-up 1 for week-2; inspect 3 guest-post opportunities |
| 5 | Follow-up 2 for non-responders (max 2 follow-ups total) |
| 6 | Record outcomes; update scoreboard; plan Wave 2 |

## Prohibited tactics

- PBNs, hacked links, comment/profile spam
- Bulk Fiverr link packages
- Fake press release blasts
- Adult/malware/pharma neighborhoods
- Paid exact-match anchor schemes

## Success metrics (honest)

- **Primary:** verified referring domains (manual Ahrefs/GSC check)
- **Secondary:** resource page citations, directory profiles
- **Not counted until verified:** claimed links without live URL
