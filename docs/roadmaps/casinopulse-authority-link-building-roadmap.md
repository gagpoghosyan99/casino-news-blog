# CasinoPulse Authority Link-Building Roadmap

Updated: 2026-07-07

## Context

On-page SEO is strong (83 canonical sitemap URLs, pillar reviews, payment/crypto hubs). The primary off-page gap is **zero referring domains**. This roadmap targets clean editorial and resource links — not spam volume.

## Anchor text policy

| Type | Share target | Examples |
|------|--------------|----------|
| Branded | 60–70% | CasinoPulse, casinopuls.site |
| Naked URL | 15–20% | https://casinopuls.site |
| Partial match | 10–15% | South Asia casino reviews, UPI casino guide |
| Exact match commercial | <5% | Avoid “best online casino” exact-match anchors |

Never buy bulk links, PBN placements, comment spam, or hacked-page injections.

## Safe outreach categories

1. **Casino affiliate directories** — submit site profile with editorial positioning (reviews + guides, not operator).
2. **Crypto / payment blogs** — pitch guest explainers on TRC-20 vs ERC-20 USDT, wallet safety, network fees.
3. **South Asia fintech blogs** — UPI/wallet friction at international merchants (non-promotional angle).
4. **Responsible gambling / harm-reduction resource pages** — offer `/responsible-gambling` as a cited resource.
5. **Casino comparison blogs** — methodology transparency, blacklist editorial standards.
6. **Webmaster / SEO resource roundups** — llms.txt, payment hub structure (technical SEO angle).

## Unsafe categories (do not use)

- PBN networks, Fiverr bulk backlinks, SAPE-style exchanges
- Spam blog comments with keyword anchors
- Fake press releases on wire services with no news value
- Hacked site injections, casino spam footers
- Paid “DR50+” link packages without editorial review
