# Wave 1 Anchor Policy

Updated: 2026-07-07

## Target distribution

| Anchor type | Share | Examples |
|-------------|-------|----------|
| Branded | **70%** | CasinoPulse, CasinoPulse Editorial |
| Naked URL | **20%** | https://casinopuls.site, casinopuls.site |
| Partial-match | **10%** | USDT TRC-20 casino guide, Bangladesh casino payments guide |
| Exact-match spam | **0%** | best online casino, top crypto casino India |

## Rules

1. **Never request** exact-match money keywords as anchor text.
2. Prefer linking to **resource pages** (guides, methodology, RG) over commercial review CTAs.
3. Directory profiles: branded or naked URL only.
4. Guest posts: one branded bio link; in-content links must be editorially justified.
5. `/go/*` affiliate redirects must **never** be used as outreach link targets.

## Per-target assignment

See `Suggested Anchor Type` and `Suggested Anchor Text` columns in [outreach-tracker.csv](../authority/outreach-tracker.csv).

## Prohibited

- PBN anchor schemes
- Sitewide footer links on unrelated sites
- Hidden or cloaked links
- Anchor text rotation services
- Links from adult/malware/pharma neighborhoods

## Verification before logging

Only update tracker when:

1. Live URL confirmed in browser
2. Link is dofollow or marked nofollow intentionally (record in Notes)
3. Target page context is editorially relevant

## Internal alignment

Homepage and pillar pages use natural branded internal anchors. Outreach anchors should mirror site voice — not keyword-stuffed.
